## 1. 공통 도구

`src/engine/rng.ts`

| 도구                    | 설명                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------ |
| `Rng` (mulberry32)      | 시드 기반 난수. 상태를 세이브에 저장하므로 같은 세이브에서 같은 선택을 하면 결과가 똑같다. |
| `chance(p)`             | 확률 p 로 true                                                                             |
| `range(a,b)` `int(a,b)` | 균등분포 실수 / 정수(양 끝 포함)                                                           |
| `normal(m, sd)`         | 정규분포 (Box-Muller)                                                                      |
| `poisson(λ)`            | 포아송 분포 (Knuth). 박스스코어 기록 수에 쓴다                                             |
| `binomial(n, p)`        | 이항분포. 슛 성공 수, 순위표 승수에 쓴다                                                   |
| `sigmoid(x)`            | `1 / (1 + e^-x)`. 승률·서머리그 합격률 등 대부분의 확률 곡선                               |

### 자주 나오는 두 가지 패턴

**① 전력 차 → 승률 (`sigmoid(차이 / 6)`)**

| 전력 차 | -12   | -6    | -3    | 0     | +3    | +6    | +12   |
| ------- | ----- | ----- | ----- | ----- | ----- | ----- | ----- |
| 승률    | 11.9% | 26.9% | 37.8% | 50.0% | 62.2% | 73.1% | 88.1% |

**② 가상 경쟁자와 비교 (`내 값 ≥ normal(기준, sd)`)**

수상·선발·합격 판정은 대부분 "내 값이 정규분포로 뽑은 경쟁자 값 이상이면 성공" 구조다. 성공 확률은 `Φ((내 값 - 기준) / sd)` (Φ = 표준정규 누적분포)이다. 내 값이 기준과 같으면 50%, 기준보다 sd 만큼 높으면 84%, 2sd 높으면 98%다.

## 2. 선수 생성

`src/engine/player.ts` `createPlayer`, `src/ui/createScreen.tsx`

### 능력치 7종

슈팅(shooting) · 돌파(finishing) · 패스(playmaking) · 리바운드(rebounding) · 수비(defense) · 운동능력(athleticism) · 스피드(speed). 범위는 20~99.

### 초기 능력치

```
raw_k  = 40 + (포지션가중치_k - 1/7) × 60 + 스타일보너스_k + U(-3, 3)
attr_k = round(raw_k × 280 / Σraw)          // 합계를 정확히 280 으로 맞춤
반올림 오차는 가중치가 가장 큰 주력 능력치에 몰아준다
```

- 생성 화면에서 유저가 각 능력치를 25~60 범위에서 재분배할 수 있다. 총합 280은 고정이다.
- 몸무게 보정: `스피드 += clamp(round((신장-100 - 몸무게) / 2.5), -10, +4)`. 적정 체중(신장-100)보다 2.5kg 무거울 때마다 -1이다.
- 신장: 포지션 범위에서 균등 추첨(PG 178~188, SG 184~193, SF 190~198, PF 195~202, C 198~210). 생성 화면에서 ±4cm 조정 가능.

### 오버롤(OVR)

포지션별 가중평균이다. 각 행의 합은 1이다.

| 포지션 | 슈팅 | 돌파 | 패스 | 리바 | 수비 | 운동 | 스피드 |
| ------ | ---- | ---- | ---- | ---- | ---- | ---- | ------ |
| PG     | .20  | .15  | .30  | .05  | .10  | .10  | .10    |
| SG     | .30  | .20  | .10  | .05  | .15  | .10  | .10    |
| SF     | .20  | .20  | .10  | .10  | .15  | .15  | .10    |
| PF     | .10  | .20  | .05  | .30  | .15  | .15  | .05    |
| C      | .05  | .20  | .05  | .35  | .20  | .10  | .05    |

시작 OVR은 대략 40 전후다(합계 280 / 7 = 40).

### 잠재력 (커리어를 가장 크게 좌우하는 값)

```
등급 5개 중 하나를 균등(각 20%)하게 고르고, 구간 안에서 균등하게 뽑는다
D 60~69 · C 70~77 · B 78~84 · A 85~91 · S 92~97
그 뒤 성장 기질 보정(천재형 +5 · 노력형 −5)을 더하고 60~97 로 자른다
```

| 등급 | 범위  | 생성 확률 (기질 보정 뒤, 5,000명 실측) |
| ---- | ----- | -------------------------------------- |
| S    | 92+   | 약 24%                                 |
| A    | 85~91 | 약 20%                                 |
| B    | 78~84 | 약 18%                                 |
| C    | 70~77 | 약 20%                                 |
| D    | ~69   | 약 18%                                 |

2026-10-30 전: `round(clamp(normal(78, 7), 60, 97))`, 92 미만이면 2.8% 로 92~95 재추첨 → S 5.3% · A 14.7% · B 34.2% · C 34.9% · D 11.0%.

**잠재력은 화면에 보이지 않는다** (2026-10-30, 전에는 등급만 보였다). 성장이 `잠재력 − OVR` 에 비례하므로 초반 시즌의 OVR 상승폭이 유일한 힌트다. 생성 화면에서 스카우팅 리포트를 횟수 제한 없이 다시 뽑을 수 있고, 다시 뽑으면 잠재력도 함께 바뀌지만 보이지는 않는다.

### 숨은 특성

| 특성      | 확률                               | 효과                                                  |
| --------- | ---------------------------------- | ----------------------------------------------------- |
| 성장형    | 조숙 25% · 보통 50% · 대기만성 25% | 전성기 종료 나이 33 / 35 / 36 ([3장](#3-성장과-노쇠)) |
| 성장 기질 | 천재형 25% · 보통 50% · 노력형 25% | 아래 표                                               |
| 부상 체질 | 20%                                | 시즌 부상 확률 10% → 25%                              |
| 클러치    | 25%                                | 플레이오프·아시안게임 경기의 전력 차 +1.5             |

성장 기질 `Player.ethic` (2026-10-30, 이전 저장은 보통):

| 기질   | 잠재력 | 성장 보너스 (그 오프시즌 훈련 수 n 기준)   | 훈련 성공 시 |
| ------ | ------ | ------------------------------------------ | ------------ |
| 천재형 | +5     | n = 0 이면 −1.0                            | +1           |
| 노력형 | −5     | +0.3 × n (성공 여부 무관, 최대 4개 → +1.2) | +2           |
| 보통   | —      | —                                          | +1           |

노력형이 훈련 4개를 다 하면 잠재력 −5 를 보너스 +1.2/시즌과 능력치 +4 추가로 메운다. 훈련을 안 하면 천재형·노력형 모두 보통보다 손해다 (천재형은 −1.0, 노력형은 잠재력 −5).

**노력치** `Player.ev` (2026-10-30): 훈련 1회마다 해당 능력치의 노력치 +1 (성공 여부 무관). 능력치별 상한 20(`EV_MAX`), 합계 상한 60(`EV_TOTAL`). 효과는 [성장 분배](#능력치-분배)를 그 능력치로 기울이는 것 하나뿐이라 OVR 총 성장량은 바뀌지 않는다. 화면에서는 능력치 막대 라벨 아래와 훈련 카드에 보인다.

## 3. 성장과 노쇠

`src/engine/player.ts` `grow`, `src/engine/game.ts` `advanceSeason`

매 시즌이 끝나면 OVR 변화량 `g` 를 정하고, 그만큼 능력치에 나눠 준다.

### OVR 변화량 g

| 조건                    | 계산식                                                  |
| ----------------------- | ------------------------------------------------------- |
| 38세 이상 (급노쇠)      | `-(1.0 + 0.4 × (나이-38)) × U(0.8, 1.2) + 보너스 × 0.5` |
| 전성기 종료 나이 ~ 37세 | `-U(0.2, 0.8) + 보너스 × 0.5`                           |
| 잠재력 도달 (gap ≤ 0)   | `U(-0.5, 0.5) + 보너스 × 0.3`                           |
| 그 외 (성장기)          | `gap × 나이배율 × 출전배율 × U(0.75, 1.25) + 보너스`    |

- `gap = 잠재력 - 현재 OVR`
- 나이배율: 18세 이하 0.30, 19~21세 0.28, 22~24세 0.25, 25~27세 0.20, 28세 이상 0.12
- 출전배율: `0.7 + 0.5 × 출전시간비율` (0.7~1.2). 많이 뛸수록 빨리 큰다.
- 38세 이상은 운동능력·스피드가 매년 추가로 -1씩 깎인다.
- 2026-10-28 완화 전: 전성기 종료 31/33/34, 급노쇠 34세부터 `-(1.5 + 0.6n)`. 봇 3,000개(11장 시드) 전후: 평균 은퇴 37세 → 41세(봇 은퇴 기준도 37→41), 커리어 21 → 25시즌, 평균 최고 OVR 78.6 → 78.9.

예) 16세, 잠재력 85, OVR 45, 출전 50%: `40 × 0.30 × 0.95 ≈ 11.4` (±25%). 잠재력과의 거리에 비례하므로 남은 gap이 줄수록 성장이 느려진다.

### 보너스 합산

| 출처                       | 값                                       |
| -------------------------- | ---------------------------------------- |
| 개인 트레이너 이벤트       | +1.5                                     |
| 캠프 거절(휴식)            | +0.5                                     |
| 슬럼프 야간 훈련           | 50% +2 / 50% -1                          |
| 그 시즌 부상               | -1                                       |
| 현역 복무 시즌             | -2.5                                     |
| 상점 아이템 성장 보너스 합 | 아이템별 +0.1~+0.5 ([9장](#상점-아이템)) |
| 성장 기질 (`ethicBonus`)   | 천재형 훈련 0개 −1.0 · 노력형 +0.3/훈련  |

### 능력치 분배

```
b_k  = 포지션가중치_k + 0.1 + (집중 훈련 능력치면 0.2) + 0.02 × 노력치_k
d_k  = g × b_k / Σ(가중치_j × b_j)
```

이렇게 나누면 OVR 변화량이 정확히 g 가 된다. `+0.1` 은 주력 능력치 하나만 99로 치솟지 않게 성장을 고르게 퍼뜨린다. 노력치는 0.02/점이라 상한 20 이면 +0.4 로 집중 훈련의 두 배만큼 그 능력치로 성장이 몰린다(2026-10-30). 능력치는 20~99로 자른다. 성장기(g > 0)에 이미 99인 능력치는 `b_k = 0` 으로 분배에서 빼므로, 주력 능력치가 상한에 닿아도 성장이 남은 능력치로 돌아가 OVR 변화량은 그대로 g 다 (예전엔 잘려 나가서 가중치가 몰린 포지션일수록 손해였다).

### 잠재력과 OVR 99 도달

잠재력은 하드캡이 아니다. 보너스가 없으면 OVR 은 잠재력에 점근하지만, 보너스는 gap 과 무관하게 더해지므로 잠재력 도달 뒤에도 매 시즌 `보너스 × 0.3` 만큼 계속 오른다.

**99 근처 체감** (`topGrowthScale`, 2026-10-28): 시즌 시작 OVR 이 95 이상이면 양의 성장 g 를 절반, 97 이상이면 1/4 로 줄인다. 노쇠(g < 0)는 줄이지 않는다. 체감 전에는 잠재력 S 가 성장 보너스 +2 만 있어도 거의 100% 99 에 닿았다.

잠재력·성장 보너스별 99 도달 비율 / 커리어 최고 OVR 평균. 조건: 봇 커리어(41세 은퇴), 매 오프시즌 훈련 3종 성공, 포지션별 40명. 보너스는 상점 아이템 성장 합(+1 = 슈퍼카·바벨·소파, +2 = 8개, +3.5 = 상점 전부). 범위는 포지션별 최저~최고.

| 잠재력 | 보너스 0       | +1               | +2                 | +3.5 (상점 전부)    |
| ------ | -------------- | ---------------- | ------------------ | ------------------- |
| 92     | 0% / 93.0~93.9 | 0% / 95.8~96.4   | 0~5% / 97.1~97.7   | 80~100% / 98.8~99.0 |
| 95     | 0% / 95.6~96.0 | 0~8% / 97.2~97.8 | 28~68% / 98.2~98.7 | 98~100% / 99.0      |

체감 전(같은 조건): 잠재력 92 는 +1 에서 8~13%, +2 에서 85~98%. 잠재력 95 는 +1 에서 58~75%, +2 에서 100%.

- 99 는 잠재력 S 에 상점 투자가 크게 쌓여야 닿는다. 상점을 거의 다 사면(+3.5) 여전히 대부분 닿는다.
- PF·C 가 PG·SG 보다 도달률이 높다(+2·잠재력 95 에서 53~68% 대 28~30%). 가중치가 몰린 능력치 수가 적어 분배가 덜 퍼지기 때문으로 보인다.
- 보너스는 상점 아이템(영구 누적)과 이벤트([9장](#9-오프시즌-이벤트훈련상점))의 합이다. 수치를 바꾸면 이 표도 다시 돌린다.

### 출전시간

```
평균 출전 = 경기시간 × clamp(0.12 + 0.75 × sigmoid((OVR - 팀전력) / 4), 0.1, 0.9)
경기별 출전 = clamp(normal(평균, 평균 × 0.12), 0, 평균 × 1.3)
```

| OVR - 팀전력 | -8  | -4  | 0   | +4  | +8  | +12 |
| ------------ | --- | --- | --- | --- | --- | --- |
| 출전 비율    | 21% | 32% | 50% | 67% | 78% | 83% |

투웨이 계약은 평균 출전에 ×0.5가 붙는다.

### 개인 박스스코어

`f = 출전분 / 36`, `r(v) = 능력치 - 무대 기준 OVR` 일 때, 기본 비율은 `기준값 × 배율^r` 이다. 약점 능력치도 0으로 무너지지 않는다.

| 기록          | 계산식                                                              |
| ------------- | ------------------------------------------------------------------- |
| 야투 시도     | `Poisson(f × clamp(14 × 1.025^r(max(슈팅,돌파)), 5, 25))`           |
| 3점 시도 비율 | `clamp(0.35 + 0.012 × (슈팅 - 돌파), 0.02, 0.65)`                   |
| 3점 성공률    | `clamp(0.33 + 0.004 × r(슈팅), 0.20, 0.46)`                         |
| 2점 성공률    | `clamp(0.48 + 0.005 × r(돌파), 0.36, 0.66)`                         |
| 자유투 시도   | `Poisson(f × clamp(3.5 × 1.04^r(돌파), 0.5, 11))`                   |
| 자유투 성공률 | `clamp(0.60 + 0.004 × 슈팅, 0.45, 0.93)` (무대 보정 없음)           |
| 리바운드      | `Poisson(f × clamp(8 × 1.035^r(리바), 2, 17))`                      |
| 어시스트      | `Poisson(f × clamp(4.5 × 1.03^r(패스), 1, 10))`                     |
| 스틸          | `Poisson(f × clamp(1.2 × 1.03^r((수비+스피드)/2), 0.3, 3))`         |
| 블록          | `Poisson(f × clamp((빅맨 1.2 / 그 외 0.4) × 1.04^r(수비), 0.1, 4))` |

게임스코어(경기력 지표): `득점 + 0.7×리바 + 0.9×어시 + 1.2×(스틸+블록)`

### 승패

```
기여   = (OVR - 무대기준) × (출전분/경기시간) × 0.3
경기력 = (게임스코어 - 출전분/36 × 16) × 0.05
edge   = 팀전력 + 기여 + 경기력 + 클러치(1.5) - 상대전력
승리 확률 = sigmoid(edge / 6)
```

- 점수차: `max(1, round(|normal(edge × 0.8, 9)|))`
- 진 팀 점수: `round(normal(평균득점 - 점수차/2, 6))`
- 내 득점이 팀 점수보다 많으면 팀 점수를 내 득점까지 끌어올린다.

### 시즌 부상

| 부상 체질 | 부상 시즌 확률 | 부상 시 경기별 결장 확률 |
| --------- | -------------- | ------------------------ |
| 아님      | 10%            | U(0.1, 0.4)              |
| 부상 체질 | 25%            | U(0.1, 0.4)              |

평균 부상 시즌 비율은 이론상 15%, 실측 13%다(현역 복무·무소속 시즌 제외 효과).

### 다른 팀 승수와 남의 시리즈

### 시즌 영향력(impact)

KBL·NBA·대학 MVP류 수상은 시즌 영향력 하나로 비교한다. 시즌당 한 번만 계산한다.

```
impact = OVR
       + 8  × (출전비율 - 0.75)
       + 10 × (팀 승률 - 0.5)
       + 0.15 × (평균 게임스코어 - 출전비율×경기시간×16/36)
       + normal(0, 1)
```

- OVR에는 그 시즌 아이템 버프가 포함된다.
- 수상 자격: 팀 경기의 70% 이상 출전.
- 판정: `impact ≥ normal(기준, sd)`. impact 자체에도 sd 1 노이즈가 있으므로 실제 성공 확률은 `Φ((impact 기대값 - 기준) / √(1 + sd²))` 이다.

## 7. 진로 엔진

`src/engine/events.ts`

### 전체 흐름

```
고교(16~18세, 3시즌)
  └ 졸업: 대학 진학 or 고졸 KBL 드래프트
대학(최대 4시즌, 2학년부터 매년 얼리 엔트리 가능. 고교 OVR 64+ 면 미국 대학 제안)
  ├ KBL 드래프트 ── 미지명 → 무소속
  └ NBA 드래프트(미국 대학 재학 중 OVR 78+) ── 미지명 → 같은 해 KBL 드래프트
KBL ── FA 또는 계약 중(OVR 82+) → NBA 서머리그 도전
NBA ── FA 때 제안 없으면 KBL 복귀
```

### 고교 졸업 스카우트

대학 목록(강팀 순)에서 `OVR ≥ 대학 strength - 8 + normal(0, 2)` 인 곳을 최대 4개 제안한다. 하나도 없으면 가장 약한 두 대학이 제안한다.

OVR 64 이상이면 미국 대학(`US_COLLEGES`, 8개교) 중 무작위 2곳도 함께 제안한다. 미국 대학도 `stage` 는 `COLLEGE` 이며 소속 학교로 구분한다. 시즌은 NCAA 정규시즌 30경기 + 상위 8팀 단판 토너먼트(8강·4강·결승)이고, 리그 기준 OVR 68. 수상은 NCAA 토너먼트 우승 / 토너먼트 MOP(결승 게임스코어 22, sd 5) / 올해의 선수(impact ≥ N(76, 2)) / 득점상(평균 20, sd 2). 봇 3,000개 기준 51.7% 가 미국 대학에 간다 (11장).

### KBL 신인 드래프트

```
score = OVR + (22 - 나이) × 0.3 + normal(0, 2)
순위  = max(1, round((75 - score) × 1.2) + 1 + int(0, 2))
순위 > 20 이면 미지명 → 무소속
1~10순위 1라운드, 11~20순위 2라운드. 계약 3년
연봉  = max(KBL 연봉표(OVR), 1라운드: 11,000 - 순위×500 만원 / 2라운드: 4,200만 원)
```

| OVR (22세) | 55  | 57  | 59  | 61  | 63  | 66   | 70   | 75   | 80   |
| ---------- | --- | --- | --- | --- | --- | ---- | ---- | ---- | ---- |
| 지명 확률  | 1%  | 11% | 39% | 74% | 95% | 100% | 100% | 100% | 100% |
| 예상 순위  | -   | 19  | 19  | 18  | 16  | 13   | 8    | 3    | 1    |

2026-10-28 전 공식은 `round((70 - score) × 1.6)` 이었다. OVR 72 이상이 전부 1순위, 1라운드가 OVR 64~71 에 몰려 고점이 구분되지 않아 1순위 기준을 75 로 올리고 기울기를 줄였다. 대신 중하위권은 순위가 밀리고 지명 확률이 낮아졌다(OVR 59: 61% → 39%, 66: 8순위 → 13순위). 예상 순위는 지명된 경우의 평균(2만 회 모의).

19~20세(얼리 엔트리)면 score에 +0.6~0.9가 붙어 지명 확률이 조금 오른다.

### NBA 드래프트 (미국 대학 재학 중 OVR ≥ 78 일 때만 선택지가 열림)

조건은 `OVR ≥ LEAGUES.NCAA.level(68) + NBA_DRAFT_MARGIN(10)` — 대학 리그 평균보다 넉넉히 높은 상위권. 한국 대학(U-리그)에서는 열리지 않고 KBL 을 거쳐 서머리그로 간다 (2026-10-28 전에는 어느 대학이든 OVR 80).

```
score = OVR + (22 - 나이) × 0.6 + (신장 - 195) / 5 + 4(미국 대학 출신, NCAA_DRAFT_BONUS) + normal(0, 2)
score < 82 이면 미지명 → 같은 해 KBL 드래프트
순위 = clamp(round((93 - score) × 5.5) + 1, 1, 60)
1라운드(1~30순위): 4년 루키 계약, $13M × (1 - (순위-1)/30 × 0.8)
2라운드(31~60순위): 2년 투웨이 계약 $636,435
```

지명 확률 = `Φ((OVR + 나이·신장 보정 + 4 - 82) / 2)`. 아래 표는 미국 대학 출신(보정 +4 포함) 기준이다. 보너스가 없으면 문턱 78 에서 미지명이 92% 라 선택지가 함정이 된다.

| 조건                 | OVR 78 | 80   | 82   | 84   | 86   |
| -------------------- | ------ | ---- | ---- | ---- | ---- |
| 20세, 195cm          | 73%    | 95%  | 100% | 100% | 100% |
| 22세, 195cm          | 50%    | 84%  | 98%  | 100% | 100% |
| 20세, 205cm          | 95%    | 100% | 100% | 100% | 100% |
| 21세, 185cm          | 24%    | 62%  | 90%  | 99%  | 100% |
| 1라운드 (20세 195cm) | 1%     | 11%  | 41%  | 78%  | 96%  |

문턱 78 에서는 지명돼도 대부분 2라운드 투웨이(2년 $636k)다. 1라운드는 OVR 82 부터 현실적이다.

score 82는 60순위, 1라운드(30순위) 안에 들려면 score 약 87.7 이상이 필요하다. 어리고 클수록 유리하다.

### NBA 서머리그 도전 (KBL 경유, 실측상 가장 흔한 NBA 진출 경로)

열리는 조건: KBL FA 시장에서 OVR 80 이상, 또는 KBL 계약 중 OVR 82 이상.

```
합격 확률 = sigmoid((OVR - 85) / 1.5 + (신장 - 195) / 10)
합격 시: OVR 86 이상이면 정식 2년 계약, 아니면 투웨이 1년
실패 시: KBL FA 제안이 다시 나온다 (계약 중이었다면 KBL 잔류)
```

| 신장  | OVR 80 | 82  | 84  | 85  | 86  | 88  |
| ----- | ------ | --- | --- | --- | --- | --- |
| 185cm | 1%     | 5%  | 16% | 27% | 42% | 73% |
| 195cm | 3%     | 12% | 34% | 50% | 66% | 88% |
| 205cm | 9%     | 27% | 58% | 73% | 84% | 95% |

계약 중이면 매 오프시즌 도전할 수 있으므로 누적 확률은 표보다 높다.

소속팀 잔류 제안은 항상 1번에 고정되고 문턱도 없다(원팀 플레이, 2026-10-28. 그 전에는 KBL OVR 55·NBA 83 미만이면 소속팀 제안도 없었고, NBA 80~82 투웨이는 무작위 구단이었다). 연봉·연차는 다른 구단과 같은 식이다. KBL 복귀·전역처럼 소속팀이 없을 때는 그 리그에서 마지막으로 뛴 팀(`history` 의 마지막 해당 리그 기록, `ownTeamId`)이 1번 "(복귀)" 제안이 된다. 그 리그에서 뛴 적이 없으면 무작위 3개 구단만 온다. KBL 소속이면 FA 에서 무소속으로 떨어지는 경로는 사라졌다(무소속은 드래프트 미지명·입단 테스트 불합격으로만).

### 연장 계약

계약이 1년 남은 오프시즌(`contract.yearsLeft === 1`)에 소속팀이 연장을 제안한다. 조건은 FA 잔류 제안과 같다(KBL 은 항상, NBA 는 OVR 80 이상이고 80~82 는 투웨이). 제안은 FA 잔류 제안과 같은 식으로 만들고, 받으면 계약만 새 연봉·연차로 덮어써서 다음 FA 를 건너뛴다. 거절하면 남은 1년을 뛰고 FA 가 된다. 입대하면 다른 계약 이벤트와 함께 무효가 된다. 테스트 봇은 실측 기준선을 지키려고 연장을 거절한다.

### 병역

### 아시안게임

- 개최: 2030년부터 4년마다. 고교 시절에는 뽑히지 않는다.
- 국가대표 선발: `OVR ≥ 70 + normal(0, 1.5)`

| OVR  | 67  | 68  | 69  | 70  | 71  | 72  | 73  |
| ---- | --- | --- | --- | --- | --- | --- | --- |
| 발탁 | 2%  | 9%  | 25% | 50% | 75% | 91% | 98% |

- 금메달이면 병역 면제(예술체육요원). 복무 중이면 즉시 조기 전역한다.

### 집중 훈련 계획

매 오프시즌 능력치 하나를 고르면 다음 시즌 성장 분배에서 그 능력치 가중치가 +0.2 붙는다. "균형 훈련"은 보정이 없다.

### 훈련 미니게임

`src/engine/events.ts` `DRILLS`·`applyDrill`, `src/ui/drillEngine.ts`(진행·판정·연출), `src/ui/drill.ts`(게이지 구간)

6종목 11가지 훈련 중 오프시즌마다 **최대 4개**(`DRILL_MAX`), 종류별로 한 번. 10회 중 6회 이상 성공하면 해당 능력치가 +1(노력형 기질은 +2)이다. 성장 공식을 거치지 않고 바로 오른다. 성공 여부와 무관하게 그 능력치의 노력치가 +1 쌓인다([2장](#숨은-특성)). 이전 저장의 `shootout`·`passDrill`·`dribbleDrill` 은 `mid`·`pass`·`drib` 으로 읽는다.

| 종목     | 훈련(id)                                | 능력치   | 조작           | 판정                                                                                                                                                                                                 |
| -------- | --------------------------------------- | -------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 슈팅     | 자유투(ft) · 미들슛(mid) · 3점슛(three) | 슈팅     | 누르고 떼기    | 삼각파 게이지(주기 640·600·520ms)를 0.86(3점은 0.88) 중심의 초록 구간에서 놓으면 성공. 구간 폭은 기본 폭의 1.6 · 1 · 0.7배                                                                           |

| 패스     | 팀 패스 게임(team)                      | 패스     | 동료 고르기    | 공이 도착하는 순간(`max(380, 700 − 회차×30)` ms 뒤) 손 든 동료를 고른다. 허용 창 `110 + (능력치 − 20) × 1.4` ms, 130ms 이상 먼저 누르면 실패                                                         |

| 수비     | 수비 풋워크(foot)                       | 수비     | 방향 고르기    | 공격수가 실제로 치고 나가는 쪽(`max(420, 820 − 회차×40) × (0.8 + 능력치/250)` ms 안)을 고르면 성공. 60% 확률의 잽 스텝 중이나 대기 중에 고르면 실패                                                  |

## 12. 번역 (i18n)

`src/i18n/index.ts`

- 엔진은 한국어 문자열을 그대로 만들고 저장한다. 수상·결과·경기 라벨은 식별자이기도 해서(`awards.includes('NBA 파이널 MVP')`) 바꾸지 않는다. 세이브 형식·D1 스키마 변경 없음.
- 번역은 표시 계층에서만: `tr(한국어 원문, 변수)` 가 현재 언어 카탈로그(`src/i18n/{en,ja}/`)를 **한국어 원문을 키로** 찾는다. 없으면 정규식 패턴(`N차전`, `정규리그 N위`, `시즌 베스트 (…)`, `X 우승` 등), 그래도 없으면 원문.
- 이벤트 제목·본문·선택지와 중계 문장처럼 변수가 섞인 문장은 `Text = string | { k, v }` 로 저장한다(`k` 는 한국어 템플릿). 옛 세이브의 문자열은 그대로 표시된다. 한국어 판정이 필요하면 `ko(text)`.
- 변수 값: 문자열·숫자는 **원문 그대로 한 번만** 넣는다(선수 이름·금액·연도). 번역할 값(팀·학교·능력치·대회 결과 이름)은 `T('한국어')` 객체로 넘긴다. 중계 문장은 `text: { k: 템플릿, v: { p: 이름 } }` 처럼 중첩한다. 그래서 선수 이름이 카탈로그 키와 같거나 `{…}` 를 담아도 번역·치환되지 않는다.
- `formatMoney` 는 현재 언어로 포맷한다. 이벤트는 생성 시점 언어의 금액 문자열을 들고 있다(ponytail 천장).
- 커버리지: `i18n.test.ts` 가 봇 커리어 120개에서 나오는 모든 문장이 en/ja 로 번역되는지, `keys.test.ts` 가 소스의 `tr('…')` 리터럴이 카탈로그에 있는지 검사한다.
