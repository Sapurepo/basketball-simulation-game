## F. 3차 피드백 (2026-10-28)

### 21. 상무 전역 후 NBA 계약을 받아도 갈 수 없는 버그

**기대 동작**: NBA 소속으로 입대 → 상무 전역 → "전역 후 진로"에서 NBA 구단 제안을 고르면 그 팀으로 복귀한다.

**실제 증상**: 계약 안내 직후 "무소속 선수의 선택"(KBL 입단 테스트 / 1년 더 개인 훈련 / 은퇴)이 한 번 더 뜬다. 어느 쪽을 골라도 NBA 계약이 사라진다.

**원인** (2026-10-28 재현 확인, `events.ts` `buildOffseason`):

1. 오프시즌 시작에 `stage === 'MILITARY'` 면 `leaveService()` 가 먼저 돈다. NBA 출신은 원소속 계약을 보존하지 않으므로(`enlist` 가 KBL 계약만 `returnTo.contract` 에 둔다) `setStage(FREE)` 하고 `nbaFA` 제안 이벤트를 만든다.
2. 그 뒤 무대별 분기가 **바뀐 뒤의** `s.stage` 로 평가돼 `else if (s.stage === 'FREE')` 에 걸려 `freeChoice()` 가 큐에 하나 더 들어간다. 이벤트 순서: `전역 안내 → nbaFA → free → training`.
3. `nbaFA` 에서 NBA 제안을 받아 `sign()` 해도 뒤의 `free` 이벤트가 그대로 실행된다. `'free'` 옵션은 `setStage(FREE)` 로 무대를 되돌리고(계약 객체는 남은 채), `tryout` 은 KBL 계약으로 덮어쓰고, `retire` 는 은퇴시킨다.
4. `nbaFA` 에서 "KBL 구단과 계약"을 골라 KBL 에 서명해도 같은 `free` 이벤트가 따라와 같은 결과. 즉 **NBA 출신의 전역 경로 전부**가 깨져 있다. KBL 출신은 `leaveService` 가 원소속 계약으로 복귀시켜 `stage === 'KBL'` 분기를 타므로 정상(기존 테스트 "상무 전역 후 KBL 원소속팀으로 복귀"가 이 경로만 덮는다).
5. 아시안게임 금메달 조기 전역(`applyEvent` 안에서 `leaveService(false)`)은 이미 만들어진 큐에 `free` 가 없어 영향 없다. 테스트 봇은 22세 KBL 에서 입대하므로 NBA 출신 전역이 실측에 거의 없어 그동안 안 잡혔다.

- [x] `buildOffseason` — `discharged = s.stage === 'MILITARY'` 면 무대별 분기 전체를 건너뛴다. 전역 이벤트가 진로 선택을 담고 있다. 연장·아시안게임·훈련 이벤트는 그대로.

- [x] 전역 후 NBA 제안을 일반 NBA FA 와 같은 식으로(`nbaFaOffers` 공유): 83+ 정식, 80~82 투웨이. 원소속팀이 1번 "(복귀)".

### 20. 원팀 플레이 가능하게

현재 한 팀에서 커리어를 끝내려면 넘어야 하는 벽(`events.ts`):

| 단계                 | 현재 동작                                                                            | 원팀을 막는 지점                                    |
| -------------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------- |
| KBL 드래프트         | 지명 구단 무작위(`rng.pick(KBL_TEAMS)`)                                              | 팀을 고를 수 없다. 원팀의 출발점이 운               |
| KBL FA               | 소속팀 "(잔류)" 1번 고정(15번), 연장 제안(14번). 문턱 OVR 55                         | 사실상 가능. 55 미만이면 제안 자체가 없어 무소속    |
| NBA 서머리그 도전    | 성공 시 구단 무작위(`nbaOffers(…, 1)` 은 KBL 소속이라 own 없음, 투웨이는 `rng.pick`) | NBA 로 가는 순간 팀을 고를 수 없다                  |
| NBA 드래프트         | 지명 구단 무작위                                                                     | 같음                                                |
| NBA FA               | 소속팀 잔류 1번 고정. 문턱 OVR 83, 80~82 는 투웨이 무작위 구단, 80 미만은 KBL 복귀만 | 83 미만이면 잔류 불가. 투웨이가 다른 팀으로 보낸다  |
| NBA → KBL 복귀       | `kblOffers` 무작위 3구단(own 없음)                                                   | 원래 KBL 팀으로 못 돌아간다                         |
| 상무 전역            | KBL 출신은 원소속 복귀(정상). NBA 출신은 21번 버그                                   | 21번 고치면 NBA 출신도 FA 로 처리(잔류 제안은 없음) |
| 무소속 → 입단 테스트 | 구단 무작위                                                                          | —                                                   |

"원팀"으로 해석할 수 있는 범위 (결정 필요):

1. **잔류 보장** — FA·연장에서 소속팀이 **항상** 제안한다(문턱 미만이어도 최저 연봉·1년). 팀을 고르는 건 못 해도 "한 번 들어간 팀에선 끝까지 뛸 수 있다". NBA 투웨이도 소속팀 기준으로. 가장 작다: `withOwnTeam` 호출부 문턱 분기 2곳 + 투웨이 1곳.
2. **1 + 리그 복귀 시 원소속 우선** — NBA → KBL 복귀, 전역(NBA 출신) 때 마지막 KBL/NBA 팀을 기억해 1번 제안으로. `GameState` 에 `lastTeam: { KBL?: id, NBA?: id }` 필드 추가(세이브는 optional 이라 마이그레이션 없음). `withOwnTeam` 의 `ownId` 인자만 바꾸면 된다.
3. **2 + 원클럽맨 명예** — 프로 데뷔부터 은퇴까지 한 구단(리그 전환 없이)이면 `honors` 에 "원클럽맨" 추가, 명예의 전당 카드에 표시. `retire()` 에서 `history` 의 `team` 을 훑어 판정. D1 변경 없음(`trophies` 는 문자열 배열).
4. **드래프트 팀 선택** — 지명 구단을 고르게 하는 건 드래프트 개념과 어긋난다. 비권장. 대신 "연고 구단" 식으로 고교 지역 구단 지명 확률 가중은 가능하나 요청이 없으면 안 한다.
