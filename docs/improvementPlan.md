## 28. 스피드·운동능력 경기 반영

2026-10-30 23번 작업 중 발견: `sim.ts` 에서 스피드는 스틸 `(수비+스피드)/2` 에만, 운동능력은 어디에도 쓰이지 않았다. 둘은 OVR 가중치(0.05~0.15)와 38세 노쇠 −1 에만 들어갔고, 반응속도·벤치·스쿼트 훈련이 올리는 능력치가 경기에 영향이 없었다.

- [x] 스피드: 야투 시도 입력 `max(슈팅,돌파)×0.85 + 스피드×0.15`(속공), 2점 성공률·자유투 시도 입력 `(돌파×2 + 스피드)/3`(돌파 득점·파울 유도)
- [x] 운동능력: 리바운드 입력 `(리바×2 + 운동)/3`, 블록 입력 `(수비 + 운동)/2`
- [x] 출전시간: `minutesOvr = OVR + (운동 − OVR)×0.15` 를 `minutesFor` 에 넘긴다 (`season.ts`·`nationalTeam.ts`)
- [x] 부상 확률: `injuryScale = 1.25 − 운동/200` 을 곱한다
- [x] `game.test.ts` 2개, `engines.md` 4·11장, `odds.ts` 경기 절

**결정 ⑧** 수비 가담은 스틸로만. 승패 edge 에 능력치를 직접 넣지 않는다.
**결정 ⑨** 섞는 비율 2:1 / 1:1 / 0.85:0.15 / 출전 0.15 로 시작. 재측정 결과를 보고 조정.

재측정(봇 3,000, 23번 직후 → 28번): NBA 진출 46.0 → 45.7%, 파이널 MVP 17.0 → 13.3%, NBA MVP 20.4 → 18.0%, KBL 챔결 MVP 50.6 → 45.3%. 봇은 훈련을 안 해 스피드·운동능력이 주력보다 낮게 자라고, 섞이면서 개인 기록이 소폭 줄었다. 진출·우승은 그대로.
