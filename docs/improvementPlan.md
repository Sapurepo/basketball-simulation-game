## C. 밸런스 — 결정이 먼저

### 2. 오버롤 고점에서 고정할지

현재 규칙 (`src/engine/player.ts:grow`): 전성기 이후 매 시즌 −0.2~−0.8, 34세(`DECLINE_AGE`)부터 −1.5 에 해마다 −0.6 씩 가속, 운동능력·스피드는 추가 −1. 명예의 전당 순위는 이미 `peakOvr`(최고점) 기준이라 랭킹에는 영향이 없다.

"고정"으로 해석할 수 있는 안:

1. **표시만 고정** — 메인 화면에 현재 OVR 대신 최고 OVR 을 크게, 현재는 작게. 엔진 무변경. 가장 싸다.
2. **노쇠 완화** — `DECLINE_AGE` 를 늦추거나 감소 폭을 줄인다. 상수 2개.
3. **완전 고정** — 전성기 이후 성장 0, 노쇠 없음. 은퇴 동기가 사라져 커리어가 늘어지고, 세이브 간 공정성(이전 유저는 노쇠를 겪음)도 깨진다. 권장하지 않음.

- [ ] 1~3 중 방향 결정 (플레이어 불만이 "숫자가 줄어드는 게 싫다"인지 "경기력이 떨어지는 게 싫다"인지 확인)
- [ ] 결정에 따라 구현 (1번이면 `mainScreen.tsx` 만, 2번이면 `player.ts` 상수 + `game.test.ts`)

- [ ] `kblOffers`·`nbaOffers` — 현 소속팀 제안을 항상 1번에 고정(n 외로 추가). 라벨에 "(잔류)" 표기. 연봉은 같은 식.
- [ ] 소속팀이 없을 때(무소속·드래프트 미지명·KBL 복귀)는 그대로.
- [ ] `game.test.ts` — FA 이벤트 옵션에 현 팀이 항상 포함되는지 1건.
- 결정 필요: 잔류 제안 연봉을 시장가보다 약간 낮게(홈 디스카운트) 둘지. 기본은 동일 분포.

### 14. 계약 남았을 때 시즌 끝나고 재계약 가능하도록

현재: `game.ts:78` 에서 시즌마다 `yearsLeft--`, FA 이벤트는 `yearsLeft <= 0` 일 때만(`events.ts:321`·343). 계약 중엔 오버롤이 올라도 연봉이 고정된다.

### 17. KBL 입단 지명 순위 계산식 수정

현재 (`events.ts` `kblDraft`): `score = OVR + (22−나이)×0.3 + N(0,2)`, `pick = round((70−score)×1.6) + 1 + int(0,2)`, 20 초과 미지명. 확률표(`odds.ts:193`)는 22세 기준 OVR 70 → 2순위, 66 → 8순위.

문제 후보 (어느 것인지 확인 필요):

1. **고점 압축** — score 70 이상이면 전부 1~3순위. OVR 75 와 85 가 구분되지 않는다.
2. **나이 가중치가 약함** — 18세 고졸은 +1.2 뿐이라 대졸보다 거의 유리하지 않다. NBA 는 ×0.6.
3. **라운드 경계** — 10순위까지 1라운드인데 KBL 은 10개 구단이므로 맞지만, 연봉이 `11000 − pick×500` 으로 1순위 10,500 / 10순위 6,000 으로 떨어지는 폭이 큰지.
4. **미지명 문턱** — score 58 미만(≈OVR 57)이면 미지명. 대학 4년을 다닌 선수가 떨어지는 비율이 높은지.

- [ ] 1~4 중 피드백이 가리키는 것 확인 (실제 리포트 문구 필요)
- [ ] 계산식 수정 후 `odds.ts` 표의 "지명 확률·예상 순위" 재계산, `docs/engines.md` 7장 갱신
- [ ] `game.test.ts` 드래프트 분포 가드 조정
